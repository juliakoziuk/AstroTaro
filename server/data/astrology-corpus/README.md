# Корпус тлумачень для астрології (суспільне надбання)

Уривки з двох книг Алана Лео (1860–1917). Книги опубліковані 1899 і 1920 року, автор помер 1917-го, тож тексти вільні (США й Велика Британія). Розпізнаний текст береться з archive.org.

| Файл | Книга | Що всередині |
|---|---|---|
| `leo-afa-1899.json` | *Astrology for All* (1899), [archive.org](https://archive.org/details/astrologyforall00leogoog) | «Сонце у знаку» і «Місяць у знаку» (по 12), **116 із 144** розділів «Сонце у знаку + Місяць у знаку». Текст чистий (скан Google) |
| `leo-key-1920.json` | *The Key to Your Own Nativity* (1920), [archive.org](https://archive.org/details/dli.ernet.128062) | планета в знаку (Сонце й Місяць повно, решта розріджено), планета в будинку (78 уривків), аспекти планети до планети (42). Розпізнавання шумне: «mamage», «senously» |

## Як зібрано

```bash
cd server
# вихідні тексти (не у git): кожен у своїй теці
curl -L -o data/astrology-sources/key-to-your-own-nativity/source.txt "https://archive.org/download/dli.ernet.128062/128062-The%20Key%20To%20Your%20Own%20Nativity_djvu.txt"
curl -L -o data/astrology-sources/astrology-for-all-1899/source.txt "https://archive.org/download/astrologyforall00leogoog/astrologyforall00leogoog_djvu.txt"
node scripts/build-astro-corpus.mjs
```

Скрипт друкує, які поєднання знайдено. Заголовки шукаються з допуском на помилки розпізнавання (відстань Левенштейна), тому деякі уривки загублено, а деякі можуть бути неточно розрізані.

## Поля уривка

`kind` — `sign` (планета у знаку), `combo` (Сонце й Місяць у знаках), `house` (планета в будинку), `aspect` (планета до планети: `with`, `nature` = conjunction | benefic | adverse); `planet`, `sign` / `house` / `with`; `source`, `title`, `year`, `line` (рядок у вихідному тексті, щоб знайти місце в книзі), `words`, `text` (розпізнаний текст як є, лише з прибраними переносами).

## Чого тут немає

- **Меркурій, Венера, Марс, Юпітер, Сатурн по знаках** книги майже не містять (у «Key» по 0–4 уривки), Уран і Нептун по знаках немає зовсім, Плутона немає (відкритий 1930).
- Аспектні уривки «Key» подекуди обірвані на межі сторінки.
- Це тлумачення початку XX століття: тон категоричний (здоров'я, шлюб, смерть), тому перед показом користувачу їх треба переказувати сучасною, м'якою мовою, а не цитувати.
