## Завдання 1. Greeting на хуках (`src/App.jsx`)

Клас `Greeting` + `App` зараз працюють на `this.state`. Перепиши їх у `src/00-basics/AppGreeting.jsx` функціями.

Таблиця відповідностей:

| Клас | Функція |
|------|---------|
| `this.state = { name: props.initialName }` | `const [name, setName] = useState(initialName)` |
| `this.setState({ name: 'Me' })` | `setName('Me')` |
| `this.setState(prev => ({ show: !prev.show }))` | `setShow(prev => !prev)` |
| `this.props.onHide()` | `onHide()` (пропси деструктуруй у параметрах) |
| `clickHandler = () => {...}` | звичайна функція всередині компонента |

Що має працювати так само: кнопка ховає/показує привітання; клік на «Everyone» змінює на «Me»; другий клік на «Me» викликає `onHide` і привітання зникає.

**Пастка, на яку ти тут наштовхнешся.** У класі в `clickHandler` після `setState` є `console.log(this.state)` і перевірка `this.state.name === 'Me'`. Стан оновлюється не одразу, тому в цьому ж виклику ти ще бачиш старе значення. У функції та сама історія: після `setName('Me')` змінна `name` у цьому рендері не змінюється. Подумай, чому логіка з `if (name === 'Me')` усе одно працює при *другому* кліку, і запиши відповідь коментарем у коді.

## Завдання 3. Лічильник-пастка (`src/App.Tricky.jsx`)

Дивись: `ComponentWithInnerState` бере початкове значення з пропса `counter`: `useState(counter)`. Далі зовнішній лічильник росте, а внутрішній **не** оновлюється.

1. Запусти і переконайся в цьому на практиці (там взагалі немає `export default` — додай його, інакше не імпортується).
2. Поясни собі: `useState(initial)` використовує початкове значення тільки при першому рендері.
3. Виправ двома способами:
   - **через `key`:** `<ComponentWithInnerState key={state} counter={state} />` — React пересоздає компонент, коли ключ змінюється;
   - **без внутрішнього стану:** обчислюй значення з пропса прямо в рендері.
4. Запиши коментарем, коли з цих двох варіантів кращий.

## Завдання 4. Мутація стану (нове, без готового файлу)

Створи `src/00-basics/Mutation.jsx`:

```jsx
const [user, setUser] = useState({ name: 'Anna', age: 20 });
```

1. Кнопка, що робить `user.age++; setUser(user)` — переконайся, що **екран не оновлюється** (той самий об'єкт, React не бачить зміни).
2. Виправ: `setUser({ ...user, age: user.age + 1 })`.
3. Те саме з масивом: `const [items, setItems] = useState(['a', 'b'])`.
   - додати: `setItems([...items, 'c'])` (не `push`);
   - видалити: `setItems(items.filter(...))` (не `splice`).
